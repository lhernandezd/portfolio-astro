# Portfolio — Luis Hernandez

Personal portfolio site for Luis Hernandez, built with [Astro](https://astro.build/) (React islands for interactive pieces). Deployed on Netlify at [lhernandezd.me](https://lhernandezd.me).

## Prerequisites

- Node `22.23.2` (see [.nvmrc](.nvmrc); `nvm use` if you use nvm)

## Getting started

```sh
npm install
npm run dev
```

The site runs at `http://localhost:4321`.

## Scripts

| Script            | Description                         |
| ----------------- | ------------------------------------ |
| `npm run dev`      | Start the local dev server           |
| `npm run build`    | Production build (outputs to `dist`) |
| `npm run serve`    | Preview the production build locally |
| `npm run check`    | Astro diagnostics/type-checking      |
| `npm run lint`     | Run eslint over `.js`/`.jsx`         |
| `npm run format`   | Run prettier over `src` (incl. `.astro`) |
| `npm run clean`    | Remove `dist`/`.astro` build output  |

See [CLAUDE.md](CLAUDE.md) for project conventions (styling, component patterns, theming).
